# Student Grade Predictor

A lightweight machine-learning project that predicts a student's final grade from academic and study-related inputs.

## Goals

- Train a small, CPU-friendly regression model.
- Keep the trained model compact enough for free hosting.
- Provide a simple web interface for predictions.
- Include reproducible training and automated tests.

## Planned stack

- Python
- scikit-learn
- pandas / NumPy
- Streamlit for the demo UI
- GitHub Actions for testing

> This is an educational prediction demo. It should not be used as the sole basis for academic decisions.
